# Project maintenance

The user uses README.md as the authoring guide instead of reading CSS.

- Keep README.md updated in the same change whenever layouts/classes, expected HTML structures, animations, controls, configuration, dependencies, or file structure change.
- Explain which features come from Reveal.js, the browser, Vite, or this project's custom code.
- Document layout recipes through their HTML classes, required children, practical content limits, and copyable examples when useful.
- Clearly distinguish instructional examples from behaviour implemented in the current deck. Do not describe Auto-Animate opt-in as a choreographed morph unless matching elements implement it.
- Keep editable slide content in readable index.html. Keep engine initialization and configuration separate.
- Use vanilla HTML, CSS, JavaScript, SVG, Reveal.js, and Vite. Do not add GSAP or another animation engine.
